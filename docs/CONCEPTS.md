# 컨셉 카탈로그

각 공간을 컨셉 카테고리로 분류하고, 카테고리별 기획 레퍼런스를 자동 제안해
제이드컴퍼니 **제안서/영업/기획**에 바로 쓰는 자료를 만든다.

## 동작
```
공간 발굴 결과(PlaceRecord) → 공간유형을 컨셉 카테고리로 분류
  → config/concepts.yaml 에서 카테고리 프로파일 조회
  → 공간 분석 신호(통창/오션뷰/정원/좌식/주차 등) 반영해 '필요한 연출 요소' 가감
  → 제안서 12필드(ProposalRecord) 생성 → 엑셀(sseomlab_proposals.xlsx)
```
분류는 1차로 `space_type_to_category` 매핑을 쓰고, 운영 시 Claude 사진/문맥 분류로
정밀화할 수 있다. 제안서 컨셉 문구는 선택적으로 Claude 로 공간 맞춤 1줄을 생성한다.

## 컨셉 카테고리 (10종)
정원형 · 한옥/고택형 · 오션뷰형 · 숲속/자연형 · 루프탑/도심뷰형 ·
브런치/레스토랑형 · 갤러리/복합문화공간형 · 대형 베이커리카페형 ·
프라이빗 독채형 · 농장/목장/체험형

## 카테고리별 정의 항목 (`config/concepts.yaml`)
각 카테고리는 다음을 갖는다:
- **target_customer** — 예상 고객층
- **wedding_concepts / dol_concepts** — 추천 웨딩/돌상 컨셉
- **color_palette** — 컬러 팔레트
- **flower_direction** — 플라워 방향
- **table_setting** — 테이블 세팅
- **photo_points** — 촬영 포인트
- **risks** — 리스크(우천/좌식/해풍/동선/주차 등 사전 점검)
- **reference_keywords** — 검색·무드보드용 레퍼런스 키워드
- **proposal_copy** — 제안서에 넣을 컨셉 문구

### 예시 (요청 사례와 일치)
| 카테고리 | 웨딩 컨셉(일부) | 돌상 컨셉(일부) |
|----------|----------------|----------------|
| 정원형 | 가든웨딩, 화이트앤그린, 낮 예식, 내추럴 우드 | 야외 돌상, 피크닉형 |
| 한옥/고택형 | 전통 한옥 웨딩, 모던 한복 스냅 | 낮은 좌식 돌상, 보자기·도자기·매화·목련 |
| 오션뷰형 | 선셋 웨딩, 화이트 패브릭, 블루앤아이보리, 미니멀 플라워 | 리조트형 돌잔치 |

## 정책 조정
카테고리 추가/문구 수정/매핑 변경은 **코드 수정 없이** `config/concepts.yaml`만 편집하면 된다.
새 공간유형이 생기면 `space_type_to_category`에 한 줄 추가한다.
