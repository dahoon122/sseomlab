# 작업 플로우 설명 (ChatGPT 공유용)

> 이 문서 하나만 붙여넣으면 다른 AI(ChatGPT 등)가 프로젝트 전체 맥락을 이해하도록 작성되었습니다.

## 1. 한 줄 정의
제이드컴퍼니(대구, 웨딩·돌잔치 디렉팅) **내부용** 웨딩·돌잔치 시장 인텔리전스 시스템.
외부 고객용 홈페이지가 아니라, 공간 발굴 + 상품 기획 + 수요/공급/매출 예측 의사결정 도구(MVP).

## 2. 사업 배경
- 일반 웨딩홀과 경쟁하지 않고, 카페·식당·한옥·정원·복합문화공간·독채를 웨딩/돌잔치 공간으로 **상품화**한다.
- 대표 사례: **수수밀소**(웨딩홀이 아니지만 분위기로 전환 가능한 공간).
- 목표: 전국에서 이런 "숨은 공간"을 지속 발굴하고, 공간별 기획안과 시장 전망을 자동 생성.

## 3. 핵심 비즈니스 로직 (이게 시스템의 심장)
1. **돌잔치 = 출생 + 12개월.** 이미 집계된 월별 출생아 수가 12개월 뒤 돌잔치 수요의 선행지표.
   → 향후 ~10개월 수요는 예측이 아니라 거의 확정값.
2. **웨딩 성수기 규칙(대구).** 성수기(3·4·5·9·10·11월)엔 호텔/웨딩홀이 웨딩에 집중 →
   돌잔치 고객이 소규모/숨은 공간(카페·독채·한옥)으로 **이동** → 성수기엔 숨은 공간의 가치·수요↑.
3. **공급 부족 = 숨은공간 수요 − 수용량.** 부족이 큰 지역·시기 = 공간 확보/영업 우선순위.

## 4. 전체 작업 플로우 (3개 축)

### 축 A — 공간 발굴 + 컨셉 제안
```
공간 후보 수집(목업 CSV / 네이버 지역검색)
  → 웨딩홀·예식장·하우스웨딩 등 1차 제외 필터(키워드)
  → 공간 분석(웨딩/돌상 적합도·협업·주차·접근성·규모·야외·우천대체·촬영·프라이빗)
  → 4대 점수화(숨은공간/웨딩전환/돌상전환/협업) + 종합점수 + 등급(A~D)
  → 컨셉 카테고리 자동 분류(10종)
  → 카테고리별 웨딩/돌상 컨셉·컬러·플라워·테이블·의자·포토존·촬영·리스크 추천
  → 연락 우선순위 + 제안서 12필드 출력(엑셀/CSV)
```

### 축 B — 수요·매출 예측
```
월별 출생아 수(KOSIS / 합성)
  → +12개월 시프트 → 지역·월별 돌잔치 수요
  → ×전환율(이벤트율·서비스가능비중·점유율) → 제이드 예상 계약·매출
  → 제이드 실적 CSV로 전환율 보정(calibration)
  → 수요월 역산으로 광고 집중 시점 추천
```

### 축 C — 공급 부족 + 사업 기회
```
지역·월 돌잔치 수요 × 숨은공간 이용비중(성수기엔 상승)
  → 숨은공간 수요 vs 수용량 → 공급 부족 + 확보 추천 유형(정원/독채/한옥)
  → 지역별 종합(연간부족·성수기집중·A등급 발굴수) → 사업 기회 우선순위
```

축 A의 "A등급 발굴 수"가 축 C의 기회 리포트로 연결되어, **"어디서 어떤 공간을 확보할지"**가 나온다.

## 5. 산출물 (data/output/)
- 공간 점수표 / **A등급 공간 DB**(즉시 컨택)
- **제안서 12필드**: 공간명·지역·유형·웨딩돌상적합도·협업·예상고객층·웨딩컨셉·돌상컨셉·연출요소·레퍼런스·컨셉문구·우선순위
- 수요예측 / 광고계획 / **공급부족리포트** / **지역별기회리포트**
- 모두 엑셀 + CSV(구글시트 붙여넣기용)

## 6. 기술 구조
- Python(=src 레이아웃, pydantic 모델, typer CLI), 설정은 `config/*.yaml`(정책/코드 분리).
- **이중 경로**: 오프라인(목업 CSV + 규칙기반, 키 불필요) ↔ 실연동(네이버+Claude+KOSIS). 인터페이스 동일.
- 모듈: `collect/ analyze/ score/ concept/ demand/ export/`, 진입점 `cli.py`(run / forecast / intel).
