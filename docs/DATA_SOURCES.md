# 데이터 출처와 법적/운영 주의

이 시스템은 외부 플랫폼 데이터를 사용한다. **공식 API 우선, ToS·robots·rate limit 준수**가 원칙이다.

## 1. 네이버 (1차 수집·보강)
- **지역 검색 API** (`openapi.naver.com/v1/search/local.json`) — 상호·주소·카테고리·전화·링크
- **블로그 검색 API** (`/v1/search/blog.json`) — 리뷰 텍스트/리뷰 수 보강
- 발급: https://developers.naver.com/apps — `NAVER_CLIENT_ID/SECRET`
- 일일 호출 한도가 있으므로 검색어 매트릭스를 효율화하고 결과를 캐시한다.
- ⚠️ 네이버 **플레이스 페이지 직접 스크래핑**은 ToS/robots 위반 소지가 크다.
  공식 API로 부족한 필드는 운영자 수동 보강 또는 별도 합의된 경로로 처리한다.

## 2. 인스타그램 (노출 강도 추정용)
- ⚠️ 비공식 스크래핑은 ToS 위반. 자동 로그인/비공개 데이터 수집을 **하지 않는다**.
- 우리가 필요한 것은 "노출이 약한가"라는 **강도 추정**뿐이다.
  공개 검색 결과/해시태그 게시물 규모 같은 거시 신호로만 근사한다.
- 개인 게시물·개인정보는 저장하지 않는다.

## 3. 홈페이지/블로그 본문
- `robots.txt` 를 존중하고, `REQUEST_DELAY_SECONDS` 로 간격을 둔다.
- 소개·대관·주차 등 **사업 정보**만 추출한다.

## 4. 사진 (Claude Vision 입력)
- 공개적으로 접근 가능한 업소 사진을 분석 입력으로만 사용한다.
- 분석 후 원본을 장기 보관할 필요는 없으며, 저작권을 고려해 재배포하지 않는다.

## 5. 개인정보/연락처
- 수집하는 연락처는 **사업자 공개 연락처**(가게 전화 등)에 한정한다.
- 산출물(엑셀/시트)은 영업 목적의 내부 자료로, 외부 공개·재판매하지 않는다.

## 6. 비용/호출 관리
- Claude 호출은 2단계 스크리닝 + 상위 후보 사진 정밀로 비용을 통제한다(ARCHITECTURE 참고).
- 모든 외부 호출은 `tenacity` 지수 백오프로 재시도하되, 한도 초과 시 중단한다.

---
요약: **공식 API 우선 · 공개·사업정보 한정 · ToS/robots/rate limit 준수 · 산출물은 내부 영업용.**
