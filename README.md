# sseomlab — 제이드컴퍼니 웨딩·돌잔치 시장 인텔리전스 시스템

> 외부 고객용 홈페이지가 아닙니다. **제이드컴퍼니 내부**의 공간 발굴 + 상품 기획 + 시장 분석 + 매출/공급 예측용 의사결정 시스템(MVP)입니다.

제이드컴퍼니는 일반 웨딩홀과 경쟁하지 않고, 카페·식당·한옥·정원·복합문화공간·독채 등을
웨딩/돌잔치 공간으로 **상품화**합니다(대표 사례: 수수밀소). 이 시스템은 전국에서 그런 숨은 공간을
발굴·분석하고, 공간별 상품 기획안과 지역별 수요·공급·매출 전망까지 자동 생성합니다.

---

## 🌙 지금 상태 (아침 확인용 요약)

**실행 가능한 MVP 완성. API 키 없이 목업 데이터로 전 기능이 돌아갑니다.**

핸드폰에서도 아래 3줄만 복사하면 결과(엑셀+CSV)가 `data/output/`에 생성됩니다.

```bash
pip install -e .
python -m sseomlab intel
ls data/output
```

## 핵심 아이디어
**돌잔치는 출생 후 12개월에 열린다** → 이미 집계된 월별 출생아 수가 12개월 뒤 수요의 선행지표.
여기에 **웨딩 성수기 규칙**(성수기엔 웨딩홀이 웨딩에 집중 → 돌잔치 고객이 숨은 공간으로 이동)을
더하면, 단순 출산율이 아니라 *실제 돌잔치 시장 구조*를 반영한 수요·공급·매출 전망이 나온다.

> 🖥️ **내 PC에서 네이버 실제 데이터로 돌리려면 → [docs/LOCAL_RUN.md](docs/LOCAL_RUN.md)** (네이버 키만 필요, Claude 불필요)

## 실행 방법 (핸드폰 복사용)

```bash
# 0) 설치 (한 번만)
pip install -e .

# 1) 통합 실행 — 공간발굴 + 수요/공급/기회 리포트 한 번에 (키 불필요)
python -m sseomlab intel

# 2) 따로 실행하고 싶을 때
python -m sseomlab run --dry-run         # 공간 점수표 + 컨셉 제안서
python -m sseomlab forecast --dry-run    # 수요·매출·공급부족·광고타이밍

# 3) 실제 데이터 연동 (.env 키 입력 후)
cp .env.example .env
python -m sseomlab run --region 대구 --region 경북     # 네이버+Claude
python -m sseomlab forecast --region 부산              # KOSIS+제이드실적
```

```

  cli.py      run / forecast / intel 명령
docs/         로드맵·아키텍처·컨셉·데이터출처
tests/        23개 (제외/점수/수요/성수기공급/기회/컨셉/오프라인)
```
