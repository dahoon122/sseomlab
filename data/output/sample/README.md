# 샘플 결과물 (폰 미리보기용)

`python -m sseomlab intel`(목업 데이터)로 생성한 **예시 산출물**입니다.
GitHub 모바일 앱에서 아래 `.csv`를 누르면 **표로 렌더링**되어 바로 볼 수 있습니다.
(실데이터 아님 — `data/sample_candidates.csv` 기반 자동 생성. 실행할 때마다 갱신됨.)

## 폰에서 먼저 볼 것 (CSV)
| 파일 | 내용 |
|------|------|
| `영업키트.csv` | ⭐ 공간별 DM·전화스크립트·핵심이익·추천상품·예상객단가·연락시점 |
| `sseomlab_proposals.csv` | 제안서 12필드(컨셉·연출요소·레퍼런스) |
| `공급부족리포트.csv` | 월·지역별 수요 vs 웨딩홀수용 vs 부족분 + 확보액션 |
| `지역별기회리포트.csv` | 지역별 사업 기회 우선순위 |
| `space_db_A등급.csv` | A등급 공간 DB(즉시 컨택) |
| `sseomlab_result.csv` | 전체 공간 점수표 |
| `수요예측.csv` / `광고계획.csv` | 돌잔치 수요·매출 / 광고 집중 시점 |

## 엑셀(.xlsx)
앱에서 미리보기는 어렵고 다운로드해서 열어야 합니다. 다중시트/색상 강조 포함.
- `demand_forecast.xlsx` — 수요예측·광고계획·보정·공급부족·기회 (5시트)
- `영업키트.xlsx` / `sseomlab_proposals.xlsx` / `sseomlab_result.xlsx`
